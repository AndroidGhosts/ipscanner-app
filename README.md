About the Pro Scanner IP App: What does this app do? This app is a powerful tool for scanning IP ranges and ports, identifying active services, and their server types. Key Features: Domain Scanning: Supports multiple CIDR domains (e.g., 192.168.1.0/24). Port Scanning: Supports multiple ports simultaneously (e.g., 80, 443, 8080). Server Detection: Recognizes over 100 server types (Nginx, Cloudflare, Apache, etc.). Background Operation: Scans continue even after the application is closed. Custom Alerts: Audio and vibration alerts upon finding a successful address. Results Grouping: Automatically organizes results by server type in the sidebar. User Guide: 1. Enter the desired PA domains and ports. 2. Set the number of threads (speed) and timeout (waiting time). 3. Tap Start Scan. 4. Results are automatically saved in the Downloads/Results.txt folder.
